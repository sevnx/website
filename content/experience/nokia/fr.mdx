shortDescription: "Modernisation d'un composant logiciel embarqué en C++ pour les produits Nokia de nouvelle génération."

### Principales responsabilités

- Conception d'une architecture avec une séparation claire des responsabilités.
- Migration progressive du code C/C++ existant vers la nouvelle architecture et adaptation du code appelant.
- Simplification de la configuration pour s'adapter à différents matériels.
- Amélioration de la testabilité grâce à des abstractions qui facilitent l'utilisation de mocks et de stubs.
- Prototypage de l'intégration de tests fonctionnels vérifiant le comportement du composant via son API sur le matériel cible.
