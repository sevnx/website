## Description

Vibedle is a game where you browse an AI-generated website and guess which model made it, including whether it used a frontend skill. Each game has five rounds and up to three guesses per site, followed by a score recap.

I built it with NextJS, React, and Convex. Games are saved to the player's account, so a refresh returns them to their current round.
