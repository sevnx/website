## Description

DesCode is a mobile app for learning programming through short lessons and interactive exercises. Learners can follow a campaign, study a language or concept, or work through a curated learning path. Exercises include quizzes, code completion, code writing, and a simulated shell.

I worked on the mobile app, admin panel, Rust backend, and deployment during a team project in the third year of my Computer Science bachelor's.
